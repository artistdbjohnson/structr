## 1. What this is (and why skill practice)

Calisthenics is a ladder, not a random circuit. Pull-up → harder pull. Push-up → pike → wall. Squat → pistol progressions. You **earn the next rung** when the current one is clean with reps in reserve — not when ego says “time for muscle-ups.”

Structr frames that as **practice**: skill drills light, form honest, Bulk denser — same spine as kettlebell:

**Warm-up → Skill drills → Form → THE BULK → Cool-down**

**What we ship in this module**

| Template | Skill spine |
|----------|-------------|
| **Pull Ladder** | Hang → scap → row/negatives → strict pull-up path |
| **Push Ladder** | Push-up → pike / elevated → wall-oriented strength |
| **Squat Ladder** | Assisted squat → shrimp / step-downs → single-leg path |

> **Light safety note:** If something hurts sharp (not “working hard”), step off the bar. Film a set or find a coach when you can. One line is enough.

## 2. Safety + common mistakes

### Pull ladder

**Blueprint:** Own the hang and scapular control before chasing chin-over-bar. Negatives and rows build the middle rungs. Progress when sets are clean with a little left — not maxed every session.

**Common misses**

| Mistake | What it looks like | Better cue |
|---------|-------------------|------------|
| Skipping hangs/scaps | Jump straight to “pull-up attempts” | Dead hang + scap pulls first — every session |
| Half ROM | Chin barely moves; bounce | Full lower; chin clears on the way up when ready |
| Kipping for “strength” | Swing replaces pull | Strict path in this module; save kip for elsewhere |
| Ego advance | Harder variation before current is easy | 2 clean sessions with reserve before next rung |
| Only pull, never push | Rounded shoulders over time | Pair with Push Ladder days |

### Push ladder

**Blueprint:** Full-range push-ups before fancy angles. Pike and wall work are **skill + strength**, practiced fresh — not after you’ve already fried the shoulders.

**Common misses**

| Mistake | What it looks like | Better cue |
|---------|-------------------|------------|
| Half push-ups | Chest never near floor | Slow full ROM; elevate hands if needed, don’t cut depth |
| Banana wall hold | Soft ribs, arched low back | Ribs down; glutes soft-squeeze; long line |
| Skipping wrists | Wrists scream mid-session | Wrist prep every push/inversion day |
| Practicing cooked | Handstand attempts after heavy push | Skill early, while fresh |
| Flare & shrug | Shoulders to ears | Pack shoulders; elbows track with intent |

### Squat ladder

**Blueprint:** Bilateral honesty before single-leg circus. Assist, hold, and step-down progressions beat “attempt pistol, fall over, repeat.”

**Common misses**

| Mistake | What it looks like | Better cue |
|---------|-------------------|------------|
| Collapsing knee | Working knee caves | Knee tracks toes; hold a support lightly |
| Bouncing out | Momentum leaves the hole | Pause; own the bottom |
| Ignoring ankles | Heels lift forever | Elevate heels temporarily; keep practicing flat |
| Too much too soon | Max pistol attempts daily | Ladder rungs + reserve rule |

## 3. Our three templates

### Pull Ladder · ~35–45 min

**Purpose:** Climb from hang toward a strict pull-up (and beyond) without thrashing elbows.  
**Who it’s for:** Beginners with a bar, returners rebuilding, anyone whose “pull day” is only curls.  
**Session shape**

| Phase | What you do |
|-------|-------------|
| Warm-up | Shoulder CARs, scap circles, light hang |
| Skill drills | Scap pulls, inverted rows / band work |
| Form | Current rung @ quality (negatives / assisted / strict) |
| **THE BULK** | Density on current rung · **RPE target 7–8** |
| Cool-down | Dead hang easy, doorway, breathe |

### Push Ladder · ~35–45 min

**Purpose:** Build push strength toward pike / wall-oriented work with wrists happy.  
**Who it’s for:** Floor push-up owners ready for harder angles; wall-curious without rushing freestanding.  
**Session shape**

| Phase | What you do |
|-------|-------------|
| Warm-up | Wrist prep, scap sets, easy push-ups |
| Skill drills | Pike holds, wall walks / chest-to-wall (as ready) |
| Form | Current push rung — quality |
| **THE BULK** | Push density · **RPE target 7–8** |
| Cool-down | Wrist stretches, child’s pose, breathe |

### Squat Ladder · ~35–45 min

**Purpose:** Own single-leg progressions without reckless pistol spam.  
**Who it’s for:** After bilateral squat feels honest (goblet or bodyweight).  
**Session shape**

| Phase | What you do |
|-------|-------------|
| Warm-up | Ankle rocks, hip openers, air squats |
| Skill drills | Assisted single-leg, step-downs, holds |
| Form | Current squat rung |
| **THE BULK** | Single-leg density · **RPE target 7–8** |
| Cool-down | 90/90, fold, breathe |

Default open: **Pull Ladder** (highest “missing skill” signal for many beginners).

## 4. RPE & The Bulk

Same Bulk-required 1–10 rule. Skill-heavy inversion days can target **6–7** on Bulk when the template says skill denser than grind. Leave reserve — ladders reward tomorrow’s practice.

## 6. FAQ

**Is this a CrossFit WOD?**  
No. Skill ladder practice. Density on Bulk, not random thrusters for time.

**Which ladder first?**  
**Pull Ladder** if you lack a pull-up; otherwise rotate push/pull across the week.

**How do I know I can advance a rung?**  
Two sessions of clean sets with a little left in the tank — then step up.

**Do I need rings / parallettes?**  
Not day one. Bar + floor covers the three templates.

**Handstand freestanding today?**  
Not the day-one promise. Push Ladder builds toward wall-oriented strength; freestanding is a later chapter (also see goal shell **Bodyweight skills**).

**Relation to kettlebell / DB?**  
Same five phases. Strength from bells helps; this module owns **bodyweight progressions**.
